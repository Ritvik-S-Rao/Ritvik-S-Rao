## About

I am an M.Sc. Computer Science graduate from SRM Institute of Science and Technology based in Chennai, India. My work focuses on designing cloud architectures on AWS, automating infrastructure using Terraform and Ansible, and building secure end-to-end CI/CD pipelines with GitHub Actions and Docker.

## Featured Projects

* **[Highly Available 2-Tier AWS Architecture & CI/CD Pipeline](https://github.com/Ritvik-S-Rao/terraform-2tier-ha)** — Modular Terraform setup provisioning a multi-AZ VPC, ALB, Auto Scaling Group, and isolated RDS MySQL instance with an automated GitHub Actions workflow.
* **[End-to-End CI/CD Pipeline for Containerized Flask App](https://github.com/Ritvik-S-Rao/python-demoapp-cicd)** — Push-triggered GitHub Actions pipeline with pytest validation, Docker Hub publishing, Trivy vulnerability scanning, and Terraform-provisioned EC2 deployment.
* **[Ansible-Based Secure Server Provisioning](https://github.com/Ritvik-S-Rao/ansible-secure-server-provisioning)** — Idempotent Ansible roles for Ubuntu 24.04 hardening (UFW, SSH lockdown), Ansible Vault secrets injection, and an automated Nginx/Bash GitHub rate-limit dashboard.
* **[GitHub API & Webhook Integration Suite](https://github.com/Ritvik-S-Rao/github-api-integration-suite)** — Modular Bash toolkit for GitHub REST API rate-limit monitoring with Discord webhook alerts and repository collaborator access auditing.
* **[Pneumonia Detection from Chest X-rays with a Custom CNN](https://github.com/Ritvik-S-Rao/Pneumonia-Detection-CNN)** — Custom TensorFlow CNN achieving 0.94 recall on pneumonia classification while reducing epoch training time by over 85% compared to a VGG19 baseline.
